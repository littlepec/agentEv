# Test Set Size in *On NMT Search Errors and Model Errors: Cat Got Your Tongue?*

## Introduction and Scope of the Query

The query asks a seemingly simple factual question: what is the test set size in the study "On NMT Search Errors and Model Errors: Cat Got Your Tongue?" by Stahlberg and Byrne? Answering it requires more than a single number, because the paper reports one full test set and then deliberately restricts two later experimental sections to subsets of that test set. Consequently, the complete and precise answer has two parts: the full test set contains **2,169 sentences**, and the length-constrained experiments operate on **73.0%** and **48.3%** of that full set respectively ([Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090); [Third-party research note on Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090)). This report documents the primary figure, explains the contexts in which it is reported, clarifies the subset experiments, and assesses the methodological significance of the reported test set size for interpreting the paper's search-error and model-error findings.

## The Primary Answer: 2,169 Sentences

### Identification of the Full Test Set

The paper's main experiments use the English–German WMT news-test2015 test set. The entire English–German WMT news-test2015 test set contains **2,169 sentences**, and the paper states the test set size as a number of sentences rather than as a number of tokens or word pieces ([Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090); [Third-party research note on Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090)). The test set is a news test set, and the language pair is English–German ([Third-party research note on Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090)). This full test set size of 2,169 sentences is reported before any subset selection, which matters because several later tables and figures in the paper are computed on smaller, explicitly delimited portions of the data ([Third-party research note on Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090)).

### Full Test Set Used in the "Results Without Length Constraints" Section

The paper reports that all experiments in the results without length constraints section are conducted on the entire English–German WMT news-test2015 test set, i.e., on all 2,169 sentences ([Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090); [Third-party research note on Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090)). This full test set supports the paper's exact inference comparisons for neural machine translation search errors and model errors, and the paper's use of the entire test set in that section establishes the full test set size for the reported exact inference results ([Third-party research note on Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090)). In practical terms, the headline claims of the paper—that beam search fails to find the global best model score for more than half of the sentences, and that for more than 50% of the sentences the model assigns the global best model score to the empty translation—are grounded in this complete 2,169-sentence evaluation ([Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090)).

### Why Sentence Count Rather Than Token Count

The paper consistently frames test set size in sentences. This is consistent with how neural machine translation evaluation is typically reported: BLEU scores are computed over a test set of sentences, and the paper reports BLEU scores as its primary quality metric ([Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090)). The sentence count also drives the interpretability of percentage-based error statistics. For example, the statement that beam search fails to find the global best model score for more than half of the sentences is directly meaningful against a denominator of 2,169 sentences ([Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090)).

## Test Set Usage Across the Paper's Experiments

### The Full Set (2,169 Sentences)

The "Results Without Length Constraints" section uses all 2,169 sentences ([Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090)). The experiments in that section employ a Transformer base model trained with Tensor2Tensor on parallel WMT18 data excluding ParaCrawl, with preprocessing that includes joint subword segmentation using byte pair encoding with 32K merges ([Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090)). Decoding is performed with the SGNMT decoder, which provides an open-source implementation of the exact inference scheme ([Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090)). The main results reported on this full test set include greedy decoding yielding a BLEU score of 29.3 with a length ratio of 1.02 and 73.6% search errors, Beam-10 yielding BLEU 30.3 with a length ratio of 1.00 and 57.7% search errors, and exact search yielding BLEU 2.1 with a length ratio of 0.06 and 0.0% search errors while assigning the global best score to the empty translation for 51.8% of sentences ([Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090)).

### The Subsets (73.0% and 48.3%)

The length-constrained exact search experiments use only a subset of the test set. The paper reports that all results in the results with length constraints section are conducted on only a subset of the test set to keep the runtime under control ([Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090); [Third-party research note on Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090)). One experiment uses **73.0%** of the test set, and other experiments use **48.3%** of the test set ([Third-party research note on Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090)). These subset experiments are distinct from the full test set size of 2,169 sentences, and the paper reports the full test set size as 2,169 sentences before any subset selection ([Third-party research note on Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090)).

The 73.0% subset appears in connection with the histogram over length ratios under a minimum translation length constraint of 0.25 times the source sentence length ([Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090)). The 48.3% subset appears in connection with the exact search under length constraints, including the comparison of exact search constrained to the beam-10 hypothesis length versus the reference length, and the comparison of exact search under length normalization against Beam-30 and Beam-10 ([Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090)).

## Derived Subset Sizes and Their Interpretation

Although the paper reports the subsets as percentages rather than as sentence counts, the corresponding sentence counts can be derived from the stated full test set size of 2,169 sentences. A 73.0% subset corresponds to approximately 1,583 sentences, and a 48.3% subset corresponds to approximately 1,048 sentences (derived from Stahlberg & Byrne, 2019, and the third-party research note's reported percentages). These derived figures should be treated as approximations, because percentages may be rounded and the paper does not state the subset sizes as raw sentence counts ([Third-party research note on Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090)).

The use of subsets has a clear methodological rationale. The paper explains that constraining search to certain translation lengths increases runtime because the lower bounds become lower, and that the paper's authors therefore restricted the experiments in that section to a subset of the test set to keep runtime under control ([Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090)). The paper also notes that it stopped decoding if the decoder took longer than a day for a single sentence on a single CPU, and that exact search without length constraints is much faster and does not need maximum execution time limits ([Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090)). This asymmetry is directly tied to the test set sizes: the full 2,169-sentence set was tractable under unconstrained exact search, whereas the length-constrained variants required smaller evaluation sets.

## Significance of the Test Set Size for the Paper's Conclusions

### Adequacy and Evaluation Scale

The reported test set size is significant because it underpins two of the paper's central empirical claims. First, the paper states that beam search fails to find the global best model scores in most cases, even with a very large beam size of 100 ([Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090)). Second, the paper reports that for more than 50% of the sentences, the model assigns the global best model score to the empty translation ([Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090)). Both claims are stated as proportions over a fixed test set, and the full 2,169-sentence test set provides the denominator for those proportions ([Third-party research note on Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090)).

The paper further reports that the problems of search errors and empty translations are not specific to the Transformer base model and also occur with other architectures. The LSTM model achieves BLEU 28.6 with 58.4% search errors and 47.7% empty translations, the SliceNet model achieves BLEU 28.8 with 46.0% search errors and 41.2% empty translations, the Transformer-Base model achieves BLEU 30.3 with 57.7% search errors and 51.8% empty translations, and the Transformer-Big model achieves BLEU 31.7 with 32.1% search errors and 25.8% empty translations ([Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090)). These comparisons involve multiple systems evaluated under a common test set protocol, which reinforces the importance of the single, clearly stated full test set size.

### Search Space Scale Versus Test Set Scale

The paper contrasts the enormous size of the NMT search space with the manageable size of the test set. With a common vocabulary size of |T| = 32,000, there are already more possible translations with 20 words or fewer than atoms in the observable universe (32,000^20 > 10^82), so complete enumeration of the search space is impossible ([Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090)). Against this backdrop, an exact inference scheme that can traverse the search space for a 2,169-sentence test set is a meaningful methodological contribution, even if exact search is too slow for practical MT ([Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090)).

### Beam Size, Search Errors, and Length Ratio

The full test set also supports the paper's analysis of beam size effects. The paper reports that Beam-10 yields 15.9% fewer search errors (absolute) than greedy decoding (57.68% versus 73.58%), but that Beam-100 improves search only slightly, to 53.62% search errors, despite being 10 times slower than Beam-10 ([Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090)). The paper also reports that even a large beam size of 100 produces 53.62% search errors ([Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090)). These findings are all reported as percentages over the test set, and their interpretation presupposes the full test set of 2,169 sentences for the unconstrained experiments ([Third-party research note on Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090)).

### Long Sentences and Empty Translations

The paper reports that long source sentences are more affected by both beam search errors and the problem of empty translations, and that the global best translation is empty for almost all sentences longer than 40 tokens ([Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090)). The histogram over length ratios shows that beam search roughly follows the reference distribution but is still slightly too short, while exact search has an isolated peak in the [0.0, 0.1] bin from the empty translations ([Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090)). These analyses depend on having a sufficiently large test set to populate the length-ratio bins and the source-length bins; the 2,169-sentence test set provides that granularity ([Third-party research note on Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090)).

## Length Constraints, Runtime, and the Limits of Subset Evaluation

The length-constrained experiments illustrate a practical trade-off in exact inference research. When search is constrained to translations longer than 0.25 times the source sentence length, the empty translation is excluded from the search space, which mitigates the problem slightly but still results in a peak in the (0.3, 0.5] cluster, suggesting that the problem cannot be fixed with a length constraint alone ([Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090)). The paper also reports that exact search constrained to the Beam-10 hypothesis length does not improve over beam search, suggesting that search errors between the beam search score and the global best score for that length are insignificant enough not to affect BLEU, whereas the oracle experiment constrained to the correct reference length improved BLEU by 0.9 points ([Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090)). These results are reported on the 48.3% subset, and the paper explicitly notes that this was done to keep runtime under control ([Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090); [Third-party research note on Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090)).

The paper further reports that exact search under length normalization does not suffer from the length deficiency anymore, but is not able to match the best BLEU score under Beam-10 search, suggesting that length normalization biases search toward translations of roughly the correct length without fixing the fundamental modelling problem ([Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090)). Under length normalization, Beam-30 achieves BLEU 37.0 with a ratio of 1.03, Beam-10 achieves BLEU 36.3 with a ratio of 1.04, and exact search achieves BLEU 36.4 with a ratio of 1.03, compared with Beam-30 and Beam-10 without length normalization achieving BLEU 37.0 and 36.7 with ratios of 1.00 and 0.98 respectively ([Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090)). These comparisons are conducted on 48.3% of the test set, which is a key caveat when comparing them to the full-test-set results in the earlier section ([Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090); [Third-party research note on Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090)).

## Conclusion

The test set size in Stahlberg and Byrne's study is **2,169 sentences**, corresponding to the entire English–German WMT news-test2015 test set ([Third-party research note on Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090)). This full set is used for the results without length constraints and establishes the denominator for the paper's headline findings on search errors and empty translations ([Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090)). The length-constrained exact search experiments, by contrast, use only subsets of the test set: 73.0% for one experiment and 48.3% for others, because constraint-based search increases runtime ([Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090); [Third-party research note on Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090)). The paper reports the full test set size of 2,169 sentences before any subset selection, and the subset experiments are distinct from that full set size ([Third-party research note on Stahlberg & Byrne, 2019](https://arxiv.org/abs/1908.10090)). For any reader seeking a single answer, the correct primary figure is therefore 2,169 sentences, with the explicit qualification that two later experimental sections are based on smaller subsets of that test set.
