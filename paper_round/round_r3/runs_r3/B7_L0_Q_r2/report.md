# Test Set Size in Stahlberg and Byrne's Study of NMT Search and Model Errors

## Direct Answer to the Query

The full test set size reported in the paper is **2,169 sentences**. This figure applies to the entire **WMT news-test2015** test set used for the main neural machine translation (NMT) experiments in Stahlberg and Byrne’s study of search errors and model errors ([Stahlberg & Byrne, 2019, document_1.txt](https://arxiv.org/abs/1908.10090)). The same full test set size is independently reported in the third-party research note, which states that the entire German-English WMT news-test2015 test set contains 2,169 sentences ([Third-party research note, n.d., document_2.txt](document_2.txt)). Therefore, when the question is framed as “what is the test set size?”, the most accurate and defensible answer is **2,169 sentences**, not one of the smaller subset sizes that appear later in the paper.

This distinction is important because the paper also reports experiments conducted on **subsets** of the test set, specifically **73.0%** and **48.3%** of the test set, for the length-constrained exact search analyses ([Stahlberg & Byrne, 2019, document_1.txt](https://arxiv.org/abs/1908.10090); [Third-party research note, n.d., document_2.txt](document_2.txt)). Those percentages describe the proportion of the test set used in particular runtime-constrained experiments; they do not replace or redefine the full test set size. The full test set remains 2,169 sentences.

## Source Context and Terminology

The relevant paper is titled *On NMT Search Errors and Model Errors: Cat Got Your Tongue?* and is authored by Felix Stahlberg and Bill Byrne of the University of Cambridge ([Stahlberg & Byrne, 2019, document_1.txt](https://arxiv.org/abs/1908.10090)). The abstract states that the authors use exact search to find global best model scores under a Transformer base model “for the entire WMT15 English-German test set” ([Stahlberg & Byrne, 2019, document_1.txt](https://arxiv.org/abs/1908.10090)). The third-party research note describes the same test set as the “German-English WMT news-test2015 test set” ([Third-party research note, n.d., document_2.txt](document_2.txt)). This directionality difference—English-German versus German-English—is a naming variation in the provided sources. It does not indicate a difference in test set size. Both sources converge on the same sentence count: 2,169 sentences.

The paper’s empirical section on results without length constraints explicitly states: “We conduct all our experiments in this section on the entire English-German WMT news-test2015 test set (2,169 sentences)” ([Stahlberg & Byrne, 2019, document_1.txt](https://arxiv.org/abs/1908.10090)). That single sentence provides the clearest primary-source answer to the query. The third-party note reinforces this by stating that “the entire German-English WMT news-test2015 test set contains 2,169 sentences” and that “the paper states the test set size as a number of sentences” ([Third-party research note, n.d., document_2.txt](document_2.txt)). Thus, the unit of measurement is sentences, not tokens, documents, or parallel segments in any other unit.

## Full Test Set Size

The full test set size is **2,169 sentences**. The paper reports this number before any subset selection ([Third-party research note, n.d., document_2.txt](document_2.txt)). In other words, 2,169 is the baseline evaluation set against which the main exact inference results are computed. The third-party note emphasizes that “this full test set size of 2,169 sentences is reported before any subset selection” and that “the paper reports the full test set size as 2,169 sentences before any subset selection” ([Third-party research note, n.d., document_2.txt](document_2.txt)). This is methodologically significant because the later length-constrained experiments reduce the evaluation set for computational reasons, but they do not change the original full test set size.

The paper’s main experiments in the “Results without Length Constraints” section use the entire test set of 2,169 sentences ([Stahlberg & Byrne, 2019, document_1.txt](https://arxiv.org/abs/1908.10090)). This full set supports the paper’s comparisons between greedy search, beam search, and exact inference, including the central finding that beam search fails to find global best model scores for many sentences, and that the empty translation receives the global best model score for a substantial proportion of sentences ([Stahlberg & Byrne, 2019, document_1.txt](https://arxiv.org/abs/1908.10090)). The third-party note explicitly says that “this full test set supports the paper’s exact inference comparisons for neural machine translation search errors and model errors” ([Third-party research note, n.d., document_2.txt](document_2.txt)).

## Use of the Full Test Set in the Main Experiments

The primary experiments that answer the paper’s main research questions are conducted on the full 2,169-sentence test set. These include the results in Table 1, which compares Greedy, Beam-10, and Exact search in terms of BLEU, length ratio, search errors, and empty translations ([Stahlberg & Byrne, 2019, document_1.txt](https://arxiv.org/abs/1908.10090)). The key reported figures include a BLEU score of 29.3 for Greedy search, 30.3 for Beam-10, and 2.1 for Exact search, along with search error rates of 73.6%, 57.7%, and 0.0%, respectively ([Stahlberg & Byrne, 2019, document_1.txt](https://arxiv.org/abs/1908.10090)). These results are based on the entire 2,169-sentence test set, as stated in the same section.

The paper also reports that “even a large beam size of 100 produces 53.62% search errors” and that Beam-10 yields 57.68% search errors compared with 73.58% for greedy decoding ([Stahlberg & Byrne, 2019, document_1.txt](https://arxiv.org/abs/1908.10090)). These comparisons depend on the full test set. The third-party note confirms that “the paper’s use of the entire test set in that section establishes the full test set size for the reported exact inference results” ([Third-party research note, n.d., document_2.txt](document_2.txt)). Therefore, the 2,169-sentence figure is not merely a descriptive detail; it is the evaluation foundation for the paper’s primary claims about search errors and model errors in NMT.

## Subset Sizes in Length-Constrained Experiments

Although the full test set size is 2,169 sentences, the paper’s length-constrained exact search experiments use only subsets of that test set. The paper explains that “all results in this section are conducted on only a subset of the test set to keep the runtime under control” ([Stahlberg & Byrne, 2019, document_1.txt](https://arxiv.org/abs/1908.10090)). The third-party note identifies two specific subset proportions: one experiment uses **73.0%** of the test set, and other experiments use **48.3%** of the test set ([Third-party research note, n.d., document_2.txt](document_2.txt)). These subset sizes appear in the length-constrained analyses, not in the main unconstrained exact inference experiments.

The paper provides a concrete runtime reason for using subsets. It states that “constraining search that way increases the run time as the γ-bounds are lower” and that “we stopped decoding if the decoder took longer than a day for a single sentence on a single CPU” ([Stahlberg & Byrne, 2019, document_1.txt](https://arxiv.org/abs/1908.10090)). This explains why the length-constrained exact search could not be run on all 2,169 sentences. The 73.0% subset is associated with the histogram in Figure 5, which applies a minimum translation length constraint of 0.25 times the source sentence length ([Stahlberg & Byrne, 2019, document_1.txt](https://arxiv.org/abs/1908.10090)). The 48.3% subset is associated with the experiments reported in Table 3 and Table 4, including exact search constrained to Beam-10 length or reference length, and exact search under length normalization ([Stahlberg & Byrne, 2019, document_1.txt](https://arxiv.org/abs/1908.10090)).

The third-party note stresses that “these subset experiments are distinct from the full test set size of 2,169 sentences” and that “the paper reports the full test set size as 2,169 sentences before any subset selection” ([Third-party research note, n.d., document_2.txt](document_2.txt)). This is a crucial clarification for any reader who might encounter the percentages and mistake them for alternative test set sizes. They are coverage rates for runtime-limited analyses, not the size of the full evaluation set.

## Why the Distinction Matters for Interpretation

The distinction between the full test set size and the subset sizes is not merely terminological. It affects how the paper’s results should be interpreted. The main conclusions about search errors and empty translations are based on the full 2,169-sentence test set. For example, the paper reports that for 51.8% of the sentences, NMT assigns the global best model score to the empty translation, and that even a large beam size of 100 produces 53.62% search errors ([Stahlberg & Byrne, 2019, document_1.txt](https://arxiv.org/abs/1908.10090)). These are full-test-set findings. If a reader mistakenly treated 73.0% or 48.3% as the test set size, they would misunderstand the scope of the paper’s primary evidence.

By contrast, the length-constrained experiments are explicitly described as subset analyses. The paper states that “all results in this section are conducted on only a subset of the test set to keep the runtime under control” ([Stahlberg & Byrne, 2019, document_1.txt](https://arxiv.org/abs/1908.10090)). The third-party note reiterates that “one experiment uses 73.0% of the test set” and “other experiments use 48.3% of the test set,” and that “the paper reports these subsets for the length-constrained exact search experiments” ([Third-party research note, n.d., document_2.txt](document_2.txt)). Thus, the full test set size of 2,169 sentences remains the anchor for the paper’s evaluation design, while the subsets are secondary analyses with reduced coverage.

From a machine learning evaluation perspective, this design reflects a common trade-off: exact or exhaustive search procedures can be computationally prohibitive, so researchers may restrict certain analyses to a subset of the full evaluation set. The paper’s stated reason—runtime control and the one-day-per-sentence limit—is directly tied to the computational cost of constrained exact search ([Stahlberg & Byrne, 2019, document_1.txt](https://arxiv.org/abs/1908.10090)). The full test set of 2,169 sentences therefore remains the standard against which the main exact inference results are reported, while the subset experiments provide additional, more focused evidence under length constraints.

## Source Reliability and Corroboration

The primary source for this query is the paper itself, available as document_1.txt, which is the arXiv version of Stahlberg and Byrne’s work ([Stahlberg & Byrne, 2019, document_1.txt](https://arxiv.org/abs/1908.10090)). The paper explicitly states the full test set size in its methods section: “the entire English-German WMT news-test2015 test set (2,169 sentences)” ([Stahlberg & Byrne, 2019, document_1.txt](https://arxiv.org/abs/1908.10090)). This is the most authoritative and direct evidence for the test set size.

The third-party research note in document_2.txt serves as a secondary source that corroborates the primary source. It states that “the entire German-English WMT news-test2015 test set contains 2,169 sentences” and that “the paper states the test set size as a number of sentences” ([Third-party research note, n.d., document_2.txt](document_2.txt)). The secondary source also clarifies that the full test set size is reported before any subset selection and that the subset experiments are distinct from the full test set size ([Third-party research note, n.d., document_2.txt](document_2.txt)). Because both sources agree on the 2,169-sentence figure, the answer to the query is well supported.

There is one minor terminological discrepancy between the sources: document_1.txt refers to the test set as English-German, while document_2.txt refers to it as German-English ([Stahlberg & Byrne, 2019, document_1.txt](https://arxiv.org/abs/1908.10090); [Third-party research note, n.d., document_2.txt](document_2.txt)). This discrepancy concerns language direction labeling, not test set size. The paper’s abstract also mentions the “entire WMT15 English-German test set,” which aligns with document_1.txt ([Stahlberg & Byrne, 2019, document_1.txt](https://arxiv.org/abs/1908.10090)). For the purposes of answering “what is the test set size?”, the directionality label does not alter the reported count. The count is consistently 2,169 sentences.

## Conclusion

The test set size in Stahlberg and Byrne’s study is **2,169 sentences** for the full WMT news-test2015 test set ([Stahlberg & Byrne, 2019, document_1.txt](https://arxiv.org/abs/1908.10090); [Third-party research note, n.d., document_2.txt](document_2.txt)). This full set is used in the main experiments without length constraints, which form the basis for the paper’s central claims about NMT search errors and model errors. The length-constrained exact search experiments use only subsets—73.0% and 48.3%—because constraining search increases runtime, sometimes to more than a day per sentence on a single CPU ([Stahlberg & Byrne, 2019, document_1.txt](https://arxiv.org/abs/1908.10090); [Third-party research note, n.d., document_2.txt](document_2.txt)). Those subset percentages should not be mistaken for the full test set size. The paper reports the full test set size as 2,169 sentences before any subset selection, and both the primary and secondary sources agree on that number ([Stahlberg & Byrne, 2019, document_1.txt](https://arxiv.org/abs/1908.10090); [Third-party research note, n.d., document_2.txt](document_2.txt)).
