# Test Set Size in the NMT Search Error and Model Error Study

## Direct Answer

The test set size at issue is **2,169 sentences**. This figure refers to the entire English-German WMT news-test2015 test set used in the neural machine translation (NMT) study on search errors and model errors ([document_1.txt](document_1.txt); [document_2.txt](document_2.txt)). The paper reports that all experiments in its results section without length constraints are conducted on the entire English-German WMT news-test2015 test set, which contains 2,169 sentences ([document_1.txt](document_1.txt)). A third-party research note corroborates that the full English-German WMT news-test2015 test set contains 2,169 sentences and that this full size is reported before any subset selection ([document_2.txt](document_2.txt)). Therefore, when the question asks for “the test set size,” the appropriate answer is **2,169 sentences**, not the smaller subset sizes used in later length-constrained experiments.

## Source Evidence for the Full Test Set Size

The primary source, document_1.txt, provides the most direct statement. In the section titled “Results without Length Constraints,” it states: “We conduct all our experiments in this section on the entire English-German WMT news-test2015 test set (2,169 sentences) with a Transformer base model...” ([document_1.txt](document_1.txt)). This sentence explicitly identifies both the test set and its size in sentences. It also establishes that the main exact inference comparisons are based on the full test set. The same source earlier refers to the “entire WMT15 English-German test set,” which is consistent with the WMT news-test2015 designation ([document_1.txt](document_1.txt)). Thus, the full test set size is not an estimate or an approximation; it is a reported count.

The secondary source, document_2.txt, is a third-party research note that summarizes the same paper’s test set details. It states: “The entire English-German WMT news-test2015 test set contains 2,169 sentences. The paper states the test set size as a number of sentences. This full test set size of 2,169 sentences is reported before any subset selection.” ([document_2.txt](document_2.txt)). This corroborates the primary source and removes potential ambiguity about whether 2,169 refers to the full set or to a subset. Document_2.txt further notes that the test set is a news test set and that the language pair is English-German ([document_2.txt](document_2.txt)). The agreement between the primary paper content and the third-party note strengthens the reliability of the 2,169-sentence figure.

## Full Test Set Versus Length-Constrained Subsets

A key nuance in the source material is that not every experiment in the paper uses all 2,169 sentences. The full test set is used for the experiments reported in the section without length constraints, but the length-constrained exact search experiments use only subsets of the test set to keep runtime under control ([document_1.txt](document_1.txt); [document_2.txt](document_2.txt)). This distinction is essential for accurately answering the test set size question. If one were to report a subset percentage as “the test set size,” it would misrepresent the paper’s main experimental setup.

The primary source explains the reason for the subsets: constraining exact search increases runtime because the γ-bounds are lower ([document_1.txt](document_1.txt)). The authors also note that they stopped decoding if the decoder took longer than a day for a single sentence on a single CPU ([document_1.txt](document_1.txt)). By contrast, exact search without length constraints is much faster and does not need maximum execution time limits ([document_1.txt](document_1.txt)). Consequently, the length-constrained analyses are performed on smaller portions of the test set. Document_2.txt explicitly distinguishes these subset experiments from the full test set size of 2,169 sentences, stating that the full size is reported before any subset selection ([document_2.txt](document_2.txt)).

The reported subset percentages are **73.0%** and **48.3%**. Document_1.txt states that the histogram in Figure 5, which concerns a minimum translation length constraint of 0.25 times the source sentence length, was conducted on 73.0% of the test set ([document_1.txt](document_1.txt)). It also states that the experiments in Table 3 and Table 4 were conducted on 48.3% of the test set ([document_1.txt](document_1.txt)). Document_2.txt summarizes the same figures: “One experiment uses 73.0% of the test set. Other experiments use 48.3% of the test set.” ([document_2.txt](document_2.txt)). These percentages are important for interpreting the length-constrained results, but they do not change the full test set size. If one applies simple arithmetic to the full size of 2,169 sentences, 73.0% corresponds to approximately 1,583 sentences and 48.3% corresponds to approximately 1,048 sentences. Those derived sentence counts are not explicitly reported in the source material, but they follow from the reported percentages and the reported full test set size ([document_1.txt](document_1.txt); [document_2.txt](document_2.txt)).

## Why the Full Test Set Size Matters for the Paper’s Findings

The full 2,169-sentence test set is the basis for the paper’s central claims about search errors and model errors in NMT. In the main results without length constraints, the paper reports the performance of greedy search, beam search with beam size 10, and exact search ([document_1.txt](document_1.txt)). Table 1 in the source shows that greedy search achieves a BLEU score of 29.3, beam search with beam size 10 achieves 30.3, and exact search achieves only 2.1 ([document_1.txt](document_1.txt)). The same table reports that exact search has 0.0% search errors but 51.8% empty translations, while Beam-10 has 57.7% search errors and 0.0% empty translations ([document_1.txt](document_1.txt)). These results are meaningful precisely because they are computed on the full 2,169-sentence test set. If the evaluation had been conducted on a smaller subset, the reported percentages and BLEU scores would not be directly comparable to the main exact inference results.

The paper also demonstrates that the empty-translation problem is not specific to the Transformer base model. Table 2 reports results for an LSTM, SliceNet, Transformer-Base, and Transformer-Big model ([document_1.txt](document_1.txt)). For example, Transformer-Big has 25.8% empty translations under exact search, while Transformer-Base has 51.8% ([document_1.txt](document_1.txt)). These architecture comparisons are part of the results without length constraints and therefore rely on the full test set ([document_1.txt](document_1.txt)). The source further reports that long source sentences are more affected by both beam search errors and empty translations, with the global best translation being empty for almost all sentences longer than 40 tokens ([document_1.txt](document_1.txt)). Such sentence-length analyses require the full distribution of test sentences, which reinforces the importance of the 2,169-sentence figure.

By contrast, the length-constrained experiments are narrower in scope. Table 3 reports that exact search constrained to the Beam-10 hypothesis length does not improve over beam search, while exact search constrained to the reference length improves BLEU by 0.9 points ([document_1.txt](document_1.txt)). Table 4 shows that length normalization fixes translation lengths but prevents exact search from matching the BLEU score of Beam-10 ([document_1.txt](document_1.txt)). These findings are reported on 48.3% of the test set, not the full test set ([document_1.txt](document_1.txt); [document_2.txt](document_2.txt)). Similarly, Figure 5’s minimum-length constraint experiment uses 73.0% of the test set ([document_1.txt](document_1.txt); [document_2.txt](document_2.txt)). Therefore, any comparison between the main results and the length-constrained results must account for different test set sizes. The full test set size remains 2,169 sentences; the subsets are methodological choices driven by runtime constraints ([document_1.txt](document_1.txt)).

## Methodological and Reporting Considerations

The source material is consistent about the test set size, but it also illustrates a broader methodological issue in machine translation evaluation: reporting subset sizes alongside full test set sizes is essential for transparency. Document_2.txt notes that the paper reports the full test set size of 2,169 sentences before any subset selection and that the length-constrained experiments use only a subset ([document_2.txt](document_2.txt)). This is a good practice because it allows readers to distinguish between the paper’s main evaluation and its supplementary analyses. If a reader were to encounter only the 48.3% or 73.0% figures, they might incorrectly infer that the entire study used a smaller test set. The primary source, however, clearly states that the experiments without length constraints use the entire test set of 2,169 sentences ([document_1.txt](document_1.txt)). The third-party note reinforces this point by explicitly separating the full test set size from the subset experiments ([document_2.txt](document_2.txt)).

From a reliability perspective, document_1.txt is the primary source and should be prioritized for factual claims about the test set size. Document_2.txt is a secondary research note, but it is useful because it directly addresses the key question and corroborates the primary source’s number ([document_2.txt](document_2.txt)). There is no conflict between the sources: both identify the full English-German WMT news-test2015 test set as containing 2,169 sentences ([document_1.txt](document_1.txt); [document_2.txt](document_2.txt)). The only variation is in the subset percentages used for length-constrained exact search, which are explicitly reported as 73.0% and 48.3% ([document_1.txt](document_1.txt); [document_2.txt](document_2.txt)). Thus, the most defensible and accurate answer to the query is 2,169 sentences for the full test set, with the subset percentages provided as context.

A concrete opinion based on the evidence is that the full test set size should be reported as **2,169 sentences** whenever the paper’s main exact inference findings are cited. The length-constrained subset sizes should be reported separately and clearly labeled, because they are not equivalent to the full test set and may affect the precision of BLEU comparisons. The paper itself acknowledges the runtime trade-off, which justifies the subset use methodologically, but it does not change the full test set size ([document_1.txt](document_1.txt); [document_2.txt](document_2.txt)).

## Conclusion

The test set size for the main experiments in the NMT search error and model error study is **2,169 sentences**. This is the size of the entire English-German WMT news-test2015 test set, and it is the figure used in the results without length constraints ([document_1.txt](document_1.txt); [document_2.txt](document_2.txt)). The length-constrained exact search experiments use only subsets of this test set, reported as 73.0% and 48.3% of the full set to control runtime ([document_1.txt](document_1.txt); [document_2.txt](document_2.txt)). Therefore, when answering “what is the test set size?” the correct response is **2,169 sentences**, with the caveat that some supplementary length-constrained analyses are conducted on smaller subsets. This distinction is important for interpreting the paper’s BLEU scores, search error rates, and empty translation percentages accurately ([document_1.txt](document_1.txt); [document_2.txt](document_2.txt)).
