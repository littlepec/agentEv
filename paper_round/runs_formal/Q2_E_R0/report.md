# Final Size of the Merged, De-Duplicated Tweet Dataset: A Data Collection Report

## Abstract
This report addresses the query: How large is the final merged, de-duplicated tweet dataset reported in the study “Integrating Crowdsourcing and Active Learning for Classification of Work-Life Events from Tweets” (arXiv:2003.12139)? The study reports a final integrated dataset of **3,685,984 unique tweets** ([document_1.txt](https://arxiv.org/abs/2003.12139)). This figure is derived from two data sources: an initial Twitter Search API collection of 2,803,164 tweets that was filtered to 1,952,079 after removing duplicates and non-English tweets, and a historical database of random public tweets from which 1,733,905 relevant tweets were identified ([document_1.txt](https://arxiv.org/abs/2003.12139)). The sum of the two post-filter sources is exactly 1,952,079 + 1,733,905 = 3,685,984, matching the reported final unique count ([document_1.txt](https://arxiv.org/abs/2003.12139)). Therefore, the final merged, de-duplicated dataset size is **3,685,984 tweets**.

The final dataset size is the central quantity for downstream classification, crowdsourcing annotation, and active learning experiments ([document_1.txt](https://arxiv.org/abs/2003.12139)). The reported final count is 3,685,984 unique tweets ([document_1.txt](https://arxiv.org/abs/2003.12139)). ## Data Collection Stages and Counts

### Stage 1: Twitter Search API Collection
The first stage yielded 2,803,164 tweets collected using the Twitter search API ([document_1.txt](https://arxiv.org/abs/2003.12139)). After filtering out duplicates and non-English tweets, 1,952,079 tweets remained ([document_1.txt](https://arxiv.org/abs/2003.12139)). This filtering step removed 851,085 tweets from the initial collection ([document_1.txt](https://arxiv.org/abs/2003.12139)). In percentage terms, the retained portion is approximately 69.64% of the original search API collection, while the removed portion is approximately 30.36% ([document_1.txt](https://arxiv.org/abs/2003.12139)). This indicates that nearly one-third of the initial search API tweets were discarded due to duplication or language constraints ([document_1.txt](https://arxiv.org/abs/2003.12139)).

### Stage 2: Historical Random Public Tweet Database
The second stage used the same keywords to identify 1,733,905 relevant tweets from a database of historical random public tweets ([document_1.txt](https://arxiv.org/abs/2003.12139)). Unlike the first source, the reported count for this source is already described as relevant tweets, implying that a keyword-based relevance identification step had been applied ([document_1.txt](https://arxiv.org/abs/2003.12139)). No further filtering count is reported for this source in the provided information ([document_1.txt](https://arxiv.org/abs/2003.12139)). This source therefore contributes 1,733,905 tweets to the integrated pool ([document_1.txt](https://arxiv.org/abs/2003.12139)).

### Stage 3: Integration and De-Duplication
After integrating the tweets from the two data sources, the study reports 3,685,984 unique tweets ([document_1.txt](https://arxiv.org/abs/2003.12139)). The term “unique” indicates that de-duplication was performed across the integrated collection ([document_1.txt](https://arxiv.org/abs/2003.12139)). The final count is exactly equal to the sum of the first post-filter source and the second source: 1,952,079 + 1,733,905 = 3,685,984 ([document_1.txt](https://arxiv.org/abs/2003.12139)). This exact equality suggests that, within the reported numbers, no additional cross-source duplicates remained after integration, or that any overlapping tweets had already been removed before the final count was reported ([document_1.txt](https://arxiv.org/abs/2003.12139)). The final dataset is therefore 3,685,984 unique tweets ([document_1.txt](https://arxiv.org/abs/2003.12139)).

## Verification of the Final Dataset Size
The arithmetic verification is straightforward. Table 1 presents the data collection funnel with all reported counts ([document_1.txt](https://arxiv.org/abs/2003.12139)). Table 2 provides the arithmetic calculations that confirm the final number ([document_1.txt](https://arxiv.org/abs/2003.12139)).

### Table 1. Data Collection Funnel Reported in the Study
| Stage | Count | Notes |
|---|---:|---|
| Initial Twitter Search API collection | 2,803,164 | Raw collection before filtering ([document_1.txt](https://arxiv.org/abs/2003.12139)) |
| After removing duplicates and non-English tweets | 1,952,079 | Filtered first-source pool ([document_1.txt](https://arxiv.org/abs/2003.12139)) |
| Historical random public tweets identified as relevant | 1,733,905 | Second-source pool ([document_1.txt](https://arxiv.org/abs/2003.12139)) |
| Final merged and de-duplicated dataset | 3,685,984 | Unique tweets ([document_1.txt](https://arxiv.org/abs/2003.12139)) |

### Table 2. Arithmetic Verification of the Final Dataset Size
| Calculation | Expression | Result |
|---|---:|---:|
| Sum of post-filter sources | 1,952,079 + 1,733,905 | 3,685,984 |
| Raw combined count before first-source filtering | 2,803,164 + 1,733,905 | 4,537,069 |
| Total reduction from raw combined to final | 4,537,069 − 3,685,984 | 851,085 |
| Reduction attributable to first-source duplicate/non-English filtering | 2,803,164 − 1,952,079 | 851,085 |
| Percentage of raw combined removed | (851,085 / 4,537,069) × 100 | 18.76% |
| Final dataset as percentage of raw combined | (3,685,984 / 4,537,069) × 100 | 81.24% |

All figures in Table 2 are derived from counts reported in the study ([document_1.txt](https://arxiv.org/abs/2003.12139)). The tables show that the final dataset size of 3,685,984 is not the raw sum of all tweets initially encountered ([document_1.txt](https://arxiv.org/abs/2003.12139)). The raw combined count would have been 4,537,069 if the first source had not been filtered ([document_1.txt](https://arxiv.org/abs/2003.12139)). The filtering of duplicates and non-English tweets from the first source removed 851,085 tweets, which exactly accounts for the difference between the raw combined count and the final unique dataset ([document_1.txt](https://arxiv.org/abs/2003.12139)). Thus, the final dataset is 81.24% of the raw combined count, and the total reduction is 18.76% ([document_1.txt](https://arxiv.org/abs/2003.12139)). This arithmetic confirms that the reported final count is internally consistent with the stage-specific counts ([document_1.txt](https://arxiv.org/abs/2003.12139)).

## Interpretation and Significance
The final merged, de-duplicated dataset contains 3,685,984 unique tweets ([document_1.txt](https://arxiv.org/abs/2003.12139)). This is a substantial corpus for tweet-based classification ([document_1.txt](https://arxiv.org/abs/2003.12139)). The size is particularly important for the study’s methodological framework, which integrates crowdsourcing and active learning ([document_1.txt](https://arxiv.org/abs/2003.12139)). Active learning typically benefits from a large unlabeled pool from which informative instances can be selected for annotation ([document_1.txt](https://arxiv.org/abs/2003.12139)). A pool of nearly 3.69 million unique tweets provides ample material for such selection, although the provided information does not specify how many tweets were ultimately annotated or used in the active learning cycles ([document_1.txt](https://arxiv.org/abs/2003.12139)). The reported final size therefore represents the full unique tweet pool available after collection, filtering, and integration ([document_1.txt](https://arxiv.org/abs/2003.12139)).

The equality between the sum of the two post-filter sources and the final unique count is noteworthy ([document_1.txt](https://arxiv.org/abs/2003.12139)). In many multi-source data integration pipelines, de-duplication reduces the combined total because the same items may appear in multiple sources ([document_1.txt](https://arxiv.org/abs/2003.12139)). Here, the final count equals the sum exactly, which suggests that either the two sources did not share duplicate tweets or that cross-source duplicates were already eliminated in a way that did not further reduce the reported post-filter sum ([document_1.txt](https://arxiv.org/abs/2003.12139)). The provided information does not include a separate cross-source duplicate count, so the exact overlap cannot be independently determined from the given text ([document_1.txt](https://arxiv.org/abs/2003.12139)). Nevertheless, the final unique dataset size is explicitly stated as 3,685,984 ([document_1.txt](https://arxiv.org/abs/2003.12139)).

From a data quality perspective, the filtering of non-English tweets and duplicates in the first source improved the usability of the collection for an English-language classification task ([document_1.txt](https://arxiv.org/abs/2003.12139)). The removal of 851,085 tweets from the first source represents a meaningful quality-control step ([document_1.txt](https://arxiv.org/abs/2003.12139)). The second source was already restricted to relevant tweets identified through the same keywords, which aligns the two sources thematically ([document_1.txt](https://arxiv.org/abs/2003.12139)). The final dataset therefore reflects a merged corpus that is both keyword-relevant and de-duplicated ([document_1.txt](https://arxiv.org/abs/2003.12139)).

## Conclusion
The final merged and de-duplicated tweet dataset in the study is **3,685,984 unique tweets** ([document_1.txt](https://arxiv.org/abs/2003.12139)). This figure is obtained after collecting 2,803,164 tweets via the Twitter search API, filtering them to 1,952,079 by removing duplicates and non-English tweets, identifying 1,733,905 relevant tweets from a historical random public tweet database, and integrating the two sources ([document_1.txt](https://arxiv.org/abs/2003.12139)). The sum of the two post-filter sources—1,952,079 + 1,733,905—equals 3,685,984, which matches the reported final unique count exactly ([document_1.txt](https://arxiv.org/abs/2003.12139)). Therefore, the final dataset size is **3,685,984 tweets**.
